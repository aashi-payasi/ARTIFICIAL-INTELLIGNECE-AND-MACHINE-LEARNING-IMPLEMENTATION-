# ARTIFICIAL-INTELLIGNECE-AND-MACHINE-LEARNING-IMPLEMENTATION-
 SecurityCheck is a Flutter-based mobile app that uses machine learning to detect digital security threats. It analyses URLs and messages for phishing patterns, evaluates password strength, and returns a risk score with recommendations. Models are trained in Python and deployed via TensorFlow Lite for on-device inference.
